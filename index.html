05

FAQ

첫 디자인부터 제작 준비까지,
시작하기 전에 궁금한 내용을 모았어요.

01처음 옷을 디자인하는 사람도 쓸 수 있나요?

기본 아이템에서 바꾸고 싶은 옵션만 선택하면 돼요. 잘 모르는 항목은 초기 설정으로 두고, 필요한 부분부터 다듬을 수 있어요.

02작업지시서에는 어떤 내용이 담기나요?

공장에 전달할 앞뒤 도식, 치수와 소재, 장식 위치 등을 담아요. 문서를 만든 뒤에도 공장 검토와 샘플 확인이 필요해요.

03내 작업은 어떻게 보관하나요?

비로그인 작업은 현재 브라우저에, 로그인한 작업은 계정에 보관하는 방식이에요. 기기를 옮기거나 별도로 보관할 때는 원본 파일을 내보내세요.

04내 옷을 AI 모델에 입힐 수 있나요?

현재 공개 베타에서는 착장 생성 기능을 준비하고 있어요. 룩북 사진을 사용자의 디자인이 적용된 결과로 보면 안 돼요.

05미리보기대로 실제 제품이 완성되나요?

이미지는 디자인을 이해하는 참고 자료예요. 원단의 특성과 실제 핏, 봉제 결과는 작업지시서와 실물 샘플을 기준으로 확인해요.

06상담을 신청할 때 비용이 결제되나요?

곧바로 결제하는 과정은 아니에요. 공개 베타에서는 이메일 초안을 만든 뒤 직접 전송하고 작업지시서를 첨부해야 상담 요청이 전달돼요.
